- 价格来源：华秋商城阶梯价（1 片价→大货价），2026-10-18 抓取，如 [CS1237](https://www.hqchip.com/search/CS1237.html)、[ADS1232](https://www.hqchip.com/search/ADS1232.html)。

### 1.3 实际可达到的克级分辨率与漂移（算账）

1kg 传感器 + 5V 激励 + 1mV/V → 满量程输出 **5mV**；HX711 gain128 噪声 50nVrms → 理论噪声底 **约 0.01g**。
但工程上被三个因素吃掉：

| 误差源 | 1kg 量程折算 | 说明 |
|---|---|---|
| 零点温漂 0.05%FS/10K | **0.5 g / 10K** | 电池发热、手掌温度都会触发 |
| 蠕变 0.05%FS/30min | **0.5 g / 30min** | 长时间放置读数持续下沉 |
| 装配回差/偏载 | 0.2–1 g | 盘面刚度、螺丝扭矩、四角偏载 |
| **工程可重复精度** | **0.2–1 g（1kg）/ 0.4–2 g（2kg）/ 1–5 g（5kg）** | 需空载去皮 + 温度补偿 |

- **结论**：单片药 0.1–0.5g，靠廉价单点传感器**无法逐粒计数**；只能做"格内总量趋势 / 缺药提醒 / 一周用量估算"。
- 若必须克级：选 ADS1232 + 恒流/恒压激励 + 铝块热隔离 + 出厂两点校准，成本 ×5。

### 1.4 "整盘称重 + 每格 IR" vs "每格独立称重"

| 维度 | A：单点承托整盘 + 每格 IR 有无 | B：每格独立称重（7×） |
|---|---|---|
| 传感器/ADC 成本 | 1×传感器 ¥22 + HX711 ¥2 ≈ **¥24** | 7×传感器 ¥154 + ADS1234×2 ¥40 ≈ **¥194** |
| 结构 | 一块浮动托盘 + 3 点限位，简单 | 7 套独立浮动格 + 防串扰筋，模具与装配复杂 |
| 精度 | 整盘 0.5–1g，**知总量不知哪格** | 每格 0.2–1g，但格间机械串扰 + 温漂叠加 |
| 标定工时 | 1 次 | 7 次/台，产线节拍 ×7 |
| 失效模式 | 单点失效 | 任一路漂移即误报"少吃药" |
| 适用 | 首版量产 | 高端/临床依从性研究 |
| 建议 | **✅ 首版选 A（+霍尔判盖）** | ❌ 二代再评估 |

**推荐落地方案（A+）**：1kg 单点传感器承托整个 7 格盘 + 每格 IR 对射判有无 + 霍尔判盖；用"整盘差值 ÷ 当格药片平均片重"做**估算**片数，明确告知用户是估算值（避免医疗声称）。

### 避光材料（有数据，但要当心）

- 口服/外用**塑料容器**遮光判据：290–450nm 任一波长透射率 **≤10%**（USP `<661.2>`/`<671>`，被国内药包材标准广泛引用）。
- 实测：琥珀色半透明塑料瓶在 290–450nm 的透射率为 **1%–37%**，**并不能稳定满足 10% 限值**；乳白不透明瓶才达标（[Thermo 分光透射应用笔记](http://assets.thermofisher.cn/TFS-Assets/MSD/Application-Notes/AN53158-spectral-transmission-testing-pharmaceutical-containers.pdf)）。
- **结论**：单层"琥珀色 PC 板"不等于遮光。建议 **不透明 PC/ABS 主体 + 取药小窗用厚壁琥珀 PC（≥2mm）+ UV 吸收剂母粒 + 内衬遮光膜**，并**用分光光度计实测 290–450nm 曲线**（供应商提供的"UV 阻隔率"多为 380nm 单点值，不可直接采信）。
- 注意：不同厂家"UV 阻隔 PC"数据差异大，本文未取得板材厂商的完整透射曲线，**标注不确定，需实测**。

- **关键功耗结论**：语音常听 20–60mA，3000mAh 电池只能撑 **50–150h**，与"低功耗待机"冲突。对策：① 语音模组单独 LDO + 负载开关，**仅按键/开盖时上电 3–5s**；② 用 PIR/霍尔/触摸做一级唤醒，语音做二级唤醒；③ 待机只保留 RTC + 称重定时采样。

### 5.4 语音播报与"家属录音亲情语音"

- **实现路径（推荐）**：手机 App 录音（AAC/MP3，≤30s）→ 云端转码 → 设备 WiFi 下载到 **SPI Flash（16MB，约 ¥6）或 TF 卡** → ESP32 用 I2S 播放 → 功放 → 扬声器。7 格 × 4 时段 × 2 条 ≈ 56 条，16MB 足够。
- **离线版**：WT588F02B 支持"录音+回放"（需外挂 Flash 与麦克风），可做"按住说话"本地录制，但音质与容量受限。
- 器件：MEMS 麦克风（I2S 数字，如 SPH0645LM4H，约 ¥5–8，**待核**）；扬声器 **49×35mm 8Ω 2W，¥4.79**（[立创 GSPK4935PN-8R2W](https://item.szlcsc.com/550909.html)）。
- **音腔设计**：后腔 ≥1.5cm³（用泡棉+独立腔体，别和电池共用），前腔 0.3–0.5cm³，泄音孔 φ0.8–1.5mm，四周密封泡棉压紧；**3.7V 直推 8Ω 实际约 1.0–1.3W**，标称 2W 需 5V 升压。

## 8. 合规与标准

| 标准 | 适用范围 | 关键要求 | 状态 |
|---|---|---|---|
| **GB 4806.1-2016 / GB 4806.7-2023** | 与药品/食品接触的塑料件、硅胶圈 | 总迁移量、高锰酸钾消耗量、重金属、感官；需供应商**符合性声明 + 第三方检测报告** | [GB 4806.7-2023 已发布，代替 2016 版](https://www.spc.org.cn/online/b8dc1a3121134cffc41a79c1d5a84f81.html) |

## 9. 待确认清单（下单前必须闭环）

1. **称重传感器实际报价与图纸**（1kg/2kg 尺寸、安装孔、温漂曲线）——目前为区间估算；**SHT31/SHT85、ADS1234、SU-03T、CI1302、SYN6288、Air780E 裸模组、琥珀 PC 板**的真实批量价（本文标注"待核"）。
2. **语音常听功耗**实测（SU-03T 60mA 为 EVB 待机值，模组真实值需实测），据此定"一级唤醒"策略。
3. **琥珀 PC 透射曲线**实测（290–450nm）是否满足 ≤10%；**IP54 结构验证**（7 格独立盖密封累计公差为最大风险点）。
4. **医疗器械分类界定**结论（决定宣传口径与注册路径，建议正式申请分类界定）。
